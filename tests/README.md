# 계산기 점검 기록 (2026-10-19)

자동 검증 실행:

```powershell
node --test --test-isolation=none tests/calculators.test.cjs
```

실제 HTML 계산 스크립트를 실행하는 16개 검증이다. DOM 대역을 사용하므로 레이아웃이나 브라우저 통합 검사를 대신하지 않는다.

- 연봉: 6천만 원의 보험료 구성, 국민연금 상·하한, 0원 급여, 개정 자녀 공제 안내.
- 카드: 총급여 25% 경계, 신용·체크 혼합, 기본 한도, 자녀별 한도, 특별항목 추가 한도, 7천만 원 초과 구간, 잘못된 자녀 수와 수정 후 재계산.

배포 사이트 브라우저 검증:

| 사례 | 기대값 | 확인 결과 |
| --- | --- | --- |
| 연봉 6천만·비과세 월 20만·본인 1명 | 국민연금 228,000원 / 고용보험 43,200원 | 일치 |
| 월세 요건 확인·총급여 5천만·월세 연 1,200만 | 한도 1천만 × 17% = 1,700,000원 | 일치 |
| 같은 조건·총급여 55,000,001원 | 1천만 × 15% = 1,500,000원 | 일치 |
| 총급여 80,000,001원 | 공제 제외 0원 | 일치 |
| 월세 근로자 요건 모름 | 금액 대신 추가 확인 안내 | 일치 |
| 총급여 4천만·신용 1,200만·체크 300만 | 1,200,000원 소득공제 | 일치 |
| 총급여 4천만·신용 1천만 | 0원 | 일치 |
| 총급여 4천만·신용 5천만·자녀 2명 | 기본 한도 4,000,000원 | 일치 |

모바일: 홈·월세·카드 페이지에서 viewport 폭 320px / 390px을 적용해 문서 가로 넘침을 확인했다. 홈 빠른 입력 버튼 클릭과 카드·월세 결과 표시도 확인했다. 실제 모든 모바일 기기의 렌더링을 보증하지 않는다.
