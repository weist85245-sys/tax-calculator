# 계산기 점검 기록 (2026-10-19)

자동 검증 실행:

```powershell
node --test --test-isolation=none tests/calculators.test.cjs tests/finance.test.cjs tests/pages.test.cjs
```

총 125개 검증이다. 32개는 실제 연봉·카드 HTML 스크립트를 실행하고, 40개는 운영 페이지에서 공유하는 금융 계산 함수와 스크립트 연결을 검증한다. 53개는 공용 계산기 22종의 링크 해석·메타 정보·잘못된 주소 처리 및 사이트맵 연결을 검증한다. DOM 대역을 사용하므로 레이아웃이나 브라우저 통합 검사를 대신하지 않는다.

- 연봉: 6천만 원의 보험료 구성, 국민연금 상·하한, 0원 급여, 개정 자녀 공제 안내.
- 카드: 총급여 25% 경계, 신용·체크 혼합, 기본 한도, 자녀별 한도, 특별항목 추가 한도, 7천만 원 초과 구간, 잘못된 자녀 수와 수정 후 재계산.

제한: 연봉 소득세는 간이세액표 조회가 아닌 단순 추정이다. 실제 급여 정산, 모든 세법 특례와 최종 환급액을 검증한 것은 아니다. 월세 자격은 사용자 확인을 전제로 하며 자료를 통한 실제 자격 판정은 하지 않는다.

추가 입력 검증: 연봉·가족 수·자녀 수·비과세액의 범위 및 관계 오류, 음수·소수·빈 입력, 잘못된 입력에서 이전 결과 숨김과 수정 후 복구를 확인했다. 실제 브라우저에서도 가족 1명·자녀 2명 오류, 가족 3명으로 수정 후 결과 복구, 음수 연봉 보존과 오류 표시, 빠른 입력 재계산, 카드 총급여 삭제 직후 결과 숨김과 재입력 후 결과 복구를 확인했다.

추가 금융 점검: 연금 공제 한도·소득 경계·추가 납입, 국세청 퇴직소득세 예시(1억 원·20년 → 소득세 112만 원), 퇴직금 92일 평균임금 기간·통상임금 우선·상여 산입·근속과 근로시간, 대출 0%·미소 금리·0원, 월말 납입 적금의 1개월·12개월 이자와 일반과세 가정을 확인했다. 브라우저에서 대출 기본값 월 506,685원, 예금 기본값 세후 1,029,610원, 연금 기본값 소득세 공제 1,050,000원, 퇴직소득세 예시 1,120,000원, 1년 미만 퇴직금 자동 산출 중단 및 잘못된 입력 안내를 확인했다.

2026-10-20 페이지 점검: 공용 계산기 목록의 22개 선택값과 계산 분기 이름이 일치하는지 확인했다. 개별 메타 설명·제목·대표 주소, 월세·연금 전용 주소 우선, 잘못된 선택값·중복 선택값의 계산 양식 숨김을 검증했다. 브라우저에서 상속세 링크의 입력 항목과 결과, 잘못된 주소의 안내도 확인했다. 메타 정보는 브라우저에서 자바스크립트로 설정되며 검색엔진의 색인이나 순위는 보장하지 않는다.
